## 主要新增功能与修复

### 1. 上游 0.146.1 基线同步

- Codez r1 将上游基线从 0.144.4 提升到 `rust-v0.146.1`，纳入协议、thread/state、App Server、MCP、HTTP、模型、权限和 TUI 的连续更新。
- 由于两端当前标签相同，本次不再重复计算上游差异；Codez 的主要风险转为确认同步后的定制保留和行为兼容。

### 2. Cyber model 自动审查与权限行为

- 上游 0.146.1 对 cyber-capable model 使用更安全的自动审查默认值，并在终端界面解释权限变化。
- Codez r1 Release notes 明确声明包含该 upstream Cyber model permission behavior。Codez 的模型目录、App Server model schema、Guardian/permission profile 和 TUI 权限提示需要保持 `modelSpecialty` 与自动审查语义一致。
- 关联上游修复：[PR #37057](https://github.com/openai/codex/pull/37057)。

### 3. App Server 协议、线程与状态

- r1 同步 App Server JSON/TypeScript schema、thread history projection、paginated history、thread lifecycle、raw response、Apps、environment、external-agent import 和新的通知/响应结构。
- 线程存储、resume/fork/rollback、side conversation、sub-agent history 和 SQLite projection 的语义进入 Codez 0.146.1 基线，旧客户端和严格反序列化实现需要验证未知字段与新增 union/enum 变体。

### 4. MCP、HTTP、Code Mode 与模型服务

- 同步 MCP runtime refresh、OAuth credential store、Apps tool catalog、远程 MCP、Code Mode host、WebSocket/HTTP transport 和统一 HTTP client factory。
- 同步 Bedrock login/custom transport、模型目录权限消息、Realtime、standalone web search、文件上传和代理/CA/网络审批路径。
- 关键上游主题包括 realtime 与 memories 经过 HTTP client factory、MCP 启动超时、MCP OAuth 并发刷新、Code Mode Darwin 安装回退和受限的远程 MCP stdio。

### 5. 执行、沙箱、安全与 TUI

- 同步 exec-server 的响应体、JSON-RPC、stdio 和并发边界，workspace roots、ancestor discovery、Windows sandbox 网络代理和 Guardian 审查。
- 同步 TUI 的安全 buffering 文案、advanced reasoning 选择、model switching、composer、diff 展示、skills 宽度、Windows 提示和 permission profile 行为。

### 6. Codez 定制能力保留

- r1 保留 `codez` 命令、Codez branding、独立 state directory、更新 endpoint、安装布局和在线安装流程。
- 保留 macOS ARM64、Linux x86_64、Linux ARM64 三平台离线 bundle，以及 `--api-base-url`、`--api-key`、`--model`、`--bundle` 离线 API bootstrap 接口。
- Release notes 声明现有 configuration、authentication、session data 不需要迁移，在线和离线安装接口保持兼容，凭据继续使用 Codez 正常认证路径保存。

## 破坏性变化、兼容性风险与迁移注意事项

1. **App Server schema 与生成 bindings（高）**：r1 大量更新 JSON/TypeScript schema、通知、响应和协议 v2 类型。严格反序列化、穷举匹配和旧客户端必须覆盖新增字段、unknown field、union/enum 变体和通知顺序。
2. **Thread store 与 paginated history（高）**：新 projection、checkpoint、fork、resume、rollback 和 session state 需要使用真实 0.144.4/0.144.4-r9 数据验证，不能只依赖空数据启动测试。
3. **MCP/OAuth/runtime refresh（高）**：连接复用、OAuth credential store、Apps catalog、startup timeout 和并发 refresh 改变连接所有权；Codez 定制若保留旧 daemon 或 router 逻辑，可能出现 stale tools、重复连接或刷新死锁。
4. **Cyber model 自动审查（高）**：`modelSpecialty` 和更安全的自动审查默认值会改变权限提示与 reviewer 选择。若 Codez 缓存、model/list、Guardian 或 TUI 忽略该字段，可能丢失安全提示或保留过宽审批策略。
5. **HTTP/代理/CA/网络审批（高）**：登录、MCP、Apps、Bedrock、Code Mode、文件上传、remote exec 和 updater 迁移到共享 HTTP client factory 后，必须验证私有 endpoint、代理、CA、redirect 和 network approval 一致性。
6. **离线安装与 API bootstrap（中高）**：接口保持兼容不等于行为无风险。需要验证 `config.toml`、`auth.json`、model provider、API key 存储、安装回滚、bundle 平台选择和失败恢复。
7. **Code Mode 与平台发布（中高）**：Darwin 外部进程回退、Windows sandbox/network proxy、Bazel release workflow、R2 archive 和离线 bundle 清单需要真实平台回归。
8. **模型与多模态协议（中）**：model catalog、Realtime、web search、文件上传、reasoning summary 和 Bedrock 能力扩展输入面；旧 SDK 和手写 bindings 需要重新生成并验证兼容读取。

## 结论

`rust-v0.146.1` 与 Codez r1 的对应上游标签完全一致，本次没有新增的上游版本差异；主要变化是 Codez 从 0.144.4-r9 跨越同步到 0.146.1 基线。Codez r1 保留 branding、独立状态、在线/离线安装和离线 API bootstrap，同时承接 App Server、thread/state、MCP、HTTP、模型、权限和 TUI 的大范围更新。建议把协议 bindings、线程数据验证、cyber model 权限语义、网络策略一致性和三平台安装回归设为 P0 发布门槛。
